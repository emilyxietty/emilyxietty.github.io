Ghiblify v2 — New Tab Chrome Extension

React 19 + TypeScript + Vite, Chrome Manifest v3

Ghiblify replaces Chrome's new tab page with a Studio Ghibli–themed dashboard of draggable, resizable widgets — clock, weather, todos, pomodoro, sticky notes, quick links, bookmarks, and more — over a rotating background of Ghibli film stills. v1 started as a simple HTML/JS extension to liven up my new tabs after Studio Ghibli released 1,000 stills for personal use; v2 is a complete rewrite.

What's new in v2:

  • Full rewrite in React 19 + TypeScript, bundled with Vite.
  • 12 widgets, fully drag-and-drop and resizable, with an edit mode that doesn't fight you.
  • 14 themed palettes (including a glassy Frost mode) plus high-contrast accessibility.
  • Localized into 7 languages — English, 日本語, Español, Français, 中文, Português, 한국어.
  • New right sidebar with bookmark search, cross-folder drag, and dockable widgets.
  • Cursor animations — soot sprites, sparkles, petals, leaves.
  • All 45 background images now bundled locally so they load reliably worldwide.
